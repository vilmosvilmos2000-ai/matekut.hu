# Matekút

**A matematika tanulás új, egyszerű útja.**

Hivatalos weboldal: [matekut.hu](https://matekut.hu)

---

## A projektről (röviden)

A **Matekút** egy új magyar matematika-oktató platform, amelynek célja, hogy a matekot érthetővé, élvezhetővé és stresszmentessé tegye.

### Mit kínál a Matekút?

- **Egyszerű és világos magyarázatok** – a bonyolult témákat is könnyen érthető részekre bontva
- **Saját tempóban tanulás** – nincs sietség, mindenki a saját ritmusában haladhat
- **Modern, tiszta felület** – mobilról és számítógépről is kényelmesen használható
- **Gyakorlati megközelítés** – a hangsúly a megértésen és a problémamegoldáson van
- **Ingyenes alaptartalom** + később bővülő prémium anyagok
- **Help aloldal** (`help.matekut.hu`) a gyakori kérdésekhez és támogatáshoz

### Jelenlegi állapot

- A weboldal fejlesztés alatt áll
- Hamarosan indul a teljes tartalom
- Statikus oldal, GitHub Pages-en fut
